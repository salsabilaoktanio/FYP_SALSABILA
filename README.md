# Power BI Dashboard

This repository contains a Power BI dashboard for a skincare and beauty e-commerce analysis, along with the project’s source data and analysis notebooks.

## View the dashboard

1. Open the [`dashboard` folder](https://github.com/salsabilaoktanio/FYP_SALSABILA/tree/main/dashboard).
2. Select **Dashboard TP078641.pbix**.
3. On the file page, click **Download raw file**.
4. Open the downloaded `.pbix` file using **Power BI Desktop**.

You do **not** need to download the notebooks or CSV files just to view the dashboard. The report may open with its data already included. If Power BI prompts you for a data source, or you want to refresh the report, download the source workbook from the [`data` folder](https://github.com/salsabilaoktanio/FYP_SALSABILA/tree/main/data):

[Download the source Excel workbook](https://github.com/salsabilaoktanio/FYP_SALSABILA/blob/main/data/Global%20skincare%20and%20Beauty%20e-store_E-commerce%20Analysis_English.xlsx)

If prompted, follow Power BI’s instructions to locate or reconnect the source file. You may need to update the file path in Power BI if it differs from the original path used to build the report.

## Requirements

- Power BI Desktop to open and interact with the `.pbix` report.
- The source Excel workbook is only needed if Power BI requests it or if you want to refresh the data.

## Repository contents

- [`dashboard/`](https://github.com/salsabilaoktanio/FYP_SALSABILA/tree/main/dashboard) — Power BI dashboard file.
- [`data/`](https://github.com/salsabilaoktanio/FYP_SALSABILA/tree/main/data) — source workbook and analysis data files.
- Jupyter notebooks — preprocessing, exploratory data analysis, modelling, and evaluation work.
